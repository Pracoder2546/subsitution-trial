Teachers' timetables

Click Add teacher, type the name, then upload that teacher's weekly timetable (Excel or CSV).

Class timetables

Click Add class, type the name (like 9-A), then upload that class's weekly timetable.

File format (same for teachers and classes)

One row per day, one column per period. Teacher file: cells = class (empty = free). Class file: cells = subject or teacher. Days can be Mon–Fri; a sheet with days across the top also works.

Day1234
Mon9-B8-A10-C
Tue9-B7-A

Use the same class names in both (9-B matches 9B or 9 - b).
